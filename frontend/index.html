Question
What is the difference between supervised and unsupervised learning?
Click to reveal answer
Answer
Supervised learning uses labelled training data to learn a mapping from inputs to outputs. Unsupervised learning finds patterns in unlabelled data without predefined correct answers — e.g. clustering, dimensionality reduction.
